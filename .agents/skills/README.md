# Ponytail project skills

Installed from https://github.com/DietrichGebert/ponytail, version 5.2.0, commit `2961b52fc1fe6a5a87c7a959a79512e5c2f3ffe5` (MIT).

The root `AGENTS.md` supplies Ponytail coding guidance for SuggFeed. The six skills live in the Codex project discovery directory `.agents/skills`.

Use `$ponytail`, `$ponytail-review`, `$ponytail-audit`, `$ponytail-debt`, `$ponytail-gain`, or `$ponytail-help`, or request them by name in chat. Project skills use these names without the plugin namespace. A fresh Codex thread may be needed to refresh the skill catalog.

This is a project skill installation. Global plugin registration and lifecycle hooks are unavailable in this cloud environment because the Codex configuration directory is read-only. Mode changes can be requested in chat; lifecycle hooks do not persist them automatically.

To update, compare a new upstream version with these files and preserve any project edits. To uninstall, remove these six skill directories, the accompanying README/license, and the Ponytail content in root `AGENTS.md`.
