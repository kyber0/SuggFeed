## Known limits

- Native cross-document transitions depend on browser support. Firefox/Safari and physical devices were not independently exercised; unsupported transitions keep ordinary navigation.
- Reduced motion, coarse/touch input and Save-Data intentionally disable selected effects. Browser Find and keyboard scrolling select native scrolling for the rest of that document mount.
- Marquee has **no production placement**. Its sample and pause control are available only when explicitly opted in.
- The existing TypeScript watcher compiles individual scripts; regenerate the combined animation bundle with `npm run build:animations` or `npm run build:client` after editing its sources.
- Implementation is in the workspace and has **not been deployed**.
